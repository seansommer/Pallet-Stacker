# Pallet Stacker

A 3D rotate-and-stack arcade game for SUJA Game Center.

Tap cases, or use lanes 1–5, to rotate. Match the target footprint and point the shipping label out. Time your final turn in the purple zone for a Perfect bonus. Stack five layers to unlock wider, faster conveyors.

Three pallets. Three, four, and five lanes. Eight chances. Practice has unlimited chances.

Original generated arcade artwork, procedural 3D models, and original synthesized audio.
